# Gritty Fitness — Tasks Breakdown

This folder defines the tasks which are the implementation plan for Gritty Fitness. 
Features are ordered so that each one is fully testable on-device (iOS via Expo Go or development build) before moving to the next. 
Large features are split into sub-tasks.

A single feature is defined by the tasks, but they are not fully refined. Use your best judgement and ask the user for details if there is something unclear. 
Every task should be fully implemented and tested. A task is not complete if it does not have an integration test that tests covers it.
