## Feature 9: Activity Recording Additional features

* We still don't have the ability to make a workout belong to a program. When the user clicks to record an activity that activity should be able to belong to a specific program that they have. 

* For example, if they click on record activity on a specific workout that they have in their program, for example in the home screen or in the program screen, that specific workout should then be recorded for it and then when finished, the summary for the activity should be visible when the user clicks on that same activity again in both screens. 

* Also, if the user records an activity via the log workout button, afterwards when they finish, in the activity summary screen as well as later when they open it via the history for example, they should be able to map this recorded activity to an activity that is perscribed in their active program. We should automatically suggest the current day activity or if there is no activity planned for the day, they should be able to still add it so that it is visible in the program. 

* I've also noticed that when a GPS activity is being recorded. You can click on any other "record activity" button that is also GPS related and that will just redirect back to the GPS activity recording screen. This should not be possible. We should lock those activities as separate entities. 

* On the map in the record activity it always gets centered in the bottom center of the screen wherever i try to move the map. Lets center the current position in the center of the viewable area of the map and allow 5 seconds of movement before centering back after the map is moved somewhere by the user manually.

* Lastly, when a user clicks on the record run with GPS button and they get to the recording screen, we should not count this as a already recording activity. If they go back, they should be able to click to record something else, since it isn't started. Only when they click on start and actually start recording, should we show the red banner with the live activity and stop them from trying to start another activity.
